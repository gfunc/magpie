## Deviations from the design, with reasons

1. **`i18n.js` touched (add-only, +10 lines).** The design and brief name no i18n change, but `TestEveryNoticeIsTranslated` fails on any `newNotice` without translations in zh, zh-TW, ja and de, and `TestNoticesAreTemplates` forbids in-place notice prose. The two required Notices (unreadable `[thinking]`, section-wide key) therefore had to be templates with translations; the edits are pure additions in the four language tables and the `NOTICES` list. One accident during editing briefly deleted the four `MothX` lines; restored in the same commit, final diff is 10 insertions, 0 deletions.
2. **Error-returning stash write implemented inline in `kimi.go`** (lock `stashMu`, `stashLoad`, set key, `stashWrite`) rather than changing `stashPut` in `rewire.go` — that shared helper is outside this unit's owned files and returns nothing to its other callers. Same semantics: the `wrote` record write now returns an error, so `atomic(a, path)` rolls back config.toml when it fails.
3. **"recorded legacy high migrates" tested as the Apply-path assertions** rather than a hand-set stale `high` over a recorded `max`: overwriting a magpie-recorded value by hand is by design the user's say (`kimiOwn` keeps it), so the brief's "recorded high migrates too" is covered by every `a.Apply("effort", …)` assertion in `TestKimiEffortPickDrivesModelTables` (the recorded value moves with each pick); the unrecorded-legacy case has its own dedicated leg (record dropped, `high` re-owned → `max`).
4. **`kimiHighestEffort` returns the first spelling among equals** (a vendor alias like Trae's `light` and `low` beside it both rank `low`; the model's own first-listed word wins), so the emitted value is always one of the model's own words. The design's signature and "strongest by EffortRank/EffortLevel" contract are unchanged.
5. **`TestKimiUnreadableThinkingDegrades`' last leg asserts the effort field's Set is refused** on an array-table `[thinking]` (SetTOMLKey returns the type error) instead of asserting it succeeds — the design's degrade applies to the takeover writer, not to the field's own key write, which has always errored on that shape.
